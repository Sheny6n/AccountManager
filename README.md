# Account Manager

Account Manager 是一个本地桌面工具，用于管理自己的 online footprint（网络足迹），整理散落在各个网站的账户、化名和个人资料。它帮助你了解自己留下了什么信息，以及这些信息可能如何把不同网络身份联系起来，最终追溯到现实中的你。

项目的重点是身份隔离和关联线索管理。比如，两个网站使用了不同化名，却复用了用户名、头像、邮箱或个人简介，这些细节都可能暴露联系。公开展示的资料与仅平台知道的注册、恢复信息，也需要区分看待。同一身份下有意共享信息很正常，工具关心的是这种关联是否符合你希望保留的身份边界。

目前支持账户分组、自定义字段、编辑、复制、置顶和跨分组搜索。删除的账户和分组可以从回收站恢复；这只影响本地记录，不会替你删除网站上的账户。数据保存在本地 `.am` 文件中，支持可选加密和自动锁定。

程序使用 Rust、Iced 和 SQLite / SQLCipher 构建，在项目目录运行 `cargo run` 即可启动。后续功能见 [PLAN.md](PLAN.md)。
